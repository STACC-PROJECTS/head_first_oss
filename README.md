# Chaayakudi

A small site for CUSAT students to map chaya (tea) spots around campus,
split group chaya bills, and unlock a "Chayakudi Wrapped" stats card each
semester.

## Instalation

1. Clone this repo
2. Open `index.html` in your browser -- no build step needed
3. Run the Python tests: `pytest tests/`

## Project structure

| Path | Purpose |
| --- | --- |
| `index.html` | Homepage + this week's popular chaya spots
| `about.html` | About Chaayakudi, bill splitting, Wrapped |
| `css/style.css` | Site styling |
| `js/main.js` | Nav toggle + spot highlighting |
| `scripts/chayakudi_utils.py` | Bill splitting + Wrapped stats logic |
